# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

维修记录：每个事项可登记多次处理记录（处理内容、处理结果、处理时间），记录按时间倒序展示；支持编辑任意一条记录的内容、结果与时间，或移除单条记录，编辑后自动按时间重新倒序；列表显示最近处理时间，无记录的事项排在有记录的事项之后；记录随 localStorage 持久化，刷新后内容与时间不变。

## 浏览器回归测试

使用 Playwright 驱动 Chromium 做端到端回归，覆盖新增记录、倒序显示、记录编辑（改时间重排）、单条移除、刷新保持、无记录排序及既有功能（新增/状态切换/删除/本地保存）。

```bash
npx playwright install chromium
npm test
```
